# PROJECT DESCRIPTION
This project is a Java application that uses file handling and a PostgreSQL database. This application allows the user to save and read drug info from a test file and save and read patient info from a database using a menu.

# HOW IT WENT.

Once I resolved those issues, I was able to get the file handling, database connection, and menu working correctly. This project helped me understand more about Java file handling, JDBC, and connecting to a PostgreSQL database.
